### T-085 客户端路径安全统一防线（SyncPath 越界校验下沉单点）（P1 / 架构）

- **来源**：F-127 @ CloudPan.Client.Core/Services/SyncPath.cs:43-47; SyncEngine.Changes.cs:176; SyncEngine.FullScan.cs:302; FileWatcherService.cs:198-216
- **范围**：SyncPath + SyncEngine.Changes/FullScan + FileWatcherService（客户端落盘路径统一经校验）
- **依赖**：无
- **目标**：客户端对服务端下发的任意相对路径都无法写出同步根，规则 8.5 防线两端闭合（纵深防御单点成立）
- **需求**：
  - 在 Client.Core 提供与服务器对等的 LocalPathValidator：相对路径经 Path.GetFullPath 后必须仍以 syncRoot 为前缀，否则拒绝落盘
  - SyncPath.ToLocalPath 与 SyncEngine.Changes/FullScan、FileWatcherService 所有『服务端下发相对路径→同步根落盘路径』转换统一经该校验，删除散落裸拼
  - NormalizePath 在加长路径前缀前先消解 .. 段，消除越界隐蔽通道
