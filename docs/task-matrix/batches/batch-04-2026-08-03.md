### T-037 修复全量扫描误删下载中文件（远端新文件首次下载保护）（P1 / 功能）

- **来源**：F-37 @ CloudPan.Client.Core/Services/SyncEngine.Scan.cs:217-223,319-331; SyncEngine.Changes.cs:137-144; SyncEngine.Queue.cs:99-121
- **范围**：SyncEngine.Scan/Changes/Queue + 快照模型
- **依赖**：无
- **目标**：远端新文件首次下载窗口内不再被全量扫描误判为本地删除，双设备同步最日常路径的数据丢失闭环闭合
- **需求**：
  - 快照新增『本地是否曾落盘/下载完成』标记（State 用 Downloading，或单独布尔 IsDownloaded）：下载开始前创建的快照不得标记为已同步落盘

  - 补单测：下载中/下载未完成时 5 分钟兜底扫描不误删；下载完成且本地删除后正常传播删除

  - [自动] dotnet build 全绿（dotnet build CloudPan.sln -c Release）
