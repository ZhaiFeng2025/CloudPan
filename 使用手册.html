1. 什么是 CloudPan

CloudPan 是一个自托管的家庭文件同步系统。它让你的文件在家庭所有设备之间自动保持同步——就像你自己搭建的私有 iCloud，数据完全存储在你自己的硬盘上，不经过任何第三方服务器。

核心概念

你指定一台常开电脑作为服务端（同步中心），其他电脑和手机作为客户端。客户端上的文件变更会自动同步到服务端，再由服务端推送到其他客户端。

2. 安装服务端（台式机）

服务端需要安装在一台常开的 Windows 电脑上（推荐台式机）。

1
获取安装文件

从 U 盘或网络共享中，将 Server 文件夹复制到台式机上任意位置（如桌面）。

2
启动安装向导

双击 CloudPan.Server.exe，将出现蓝色安装窗口。点击「开始安装」。

如需管理权限，右键 → 以管理员身份运行。
3
记下 Token

安装完成后，窗口会显示一组 64 位字符——这是家庭共享 Token。请立即复制保存，配置客户端时需要。

Token 是访问你文件系统的唯一凭证，请妥善保管。丢失后只能重新生成。

安装完成后，服务端会以 Windows Service 形式在后台运行。右下角出现蓝色云朵图标，右键可管理。

托盘菜单

显示管理窗口查看设备列表、运行状态
打开同步文件夹快速打开文件同步目录
复制服务端地址复制 HTTPS 地址到剪贴板
复制 Token复制家庭共享 Token
显示 Token弹窗显示完整 Token
退出停止服务（需重新运行 exe 恢复）

3. 安装客户端（笔记本）

1
获取安装文件

将 Client 文件夹复制到笔记本上。

2
首次启动配置

双击 CloudPan.Client.exe。首次运行会弹出配置窗口：

服务端地址输入服务端的 IP 地址（如 http://192.168.1.100:8443）
同一 WiFi 下会自动搜索，无需手动输入
同步文件夹选择本地文件夹（默认为用户目录下的 CloudPan）
Token粘贴服务端显示的 64 位 Token
3
开始同步

点击「连接服务器」，配置会自动保存。以后每次双击桌面图标即可直接启动，无需重新配置。

提示：如果同一 WiFi 下无法自动发现服务端，请确保两台电脑在同一网段，且服务端防火墙已放行 8443 端口。

4. 日常使用

4.1 文件同步

同步全自动，不需要任何手动操作：

  • 把文件放入同步文件夹 → 自动上传到服务端
  • 其他设备自动下载 → 本地出现相同文件
  • 修改文件 → 自动同步新版本到所有设备
  • 删除文件 → 所有设备同步删除（回收站保留 30 天）

4.2 查看状态

右下角托盘图标颜色表示当前状态：

● 绿色就绪，所有文件已同步
● 蓝色正在同步中
● 黄色已暂停或有冲突
● 红色连接失败或发生错误

双击托盘图标可打开主窗口，查看详细日志和同步队列。

4.3 解决冲突

当两台设备同时修改同一文件时，CloudPan 会自动创建冲突副本（文件名后加 _冲突_时间戳）。主窗口会显示冲突警告，你可以手动选择保留哪个版本。

6. 高级设置

右键客户端托盘图标 →「设置」，可配置以下选项：

账户

修改服务端地址、同步文件夹、Token。修改后需重启客户端生效。

选择性同步

勾选需要同步的文件夹，未勾选的文件夹不会下载到本机。适合笔记本存储空间有限的情况。

带宽限制

设置上传/下载速率上限（KB/s），0 表示不限速。适用于网络带宽有限的场景。

存储

查看同步文件夹占用空间和磁盘剩余空间。

开机自启

托盘菜单可勾选「开机自动启动」，客户端将在 Windows 启动时自动运行。

7. Android 手机

7.1 安装

1
将 CloudPan.apk 文件传输到手机，点击安装。
2
打开 App，输入服务端地址和 Token。自动连接后显示文件列表。

7.2 照片备份

首次连接成功后会自动弹窗询问是否启用照片备份。也可在设置中手动开启。支持：

  • 仅 Wi-Fi 网络下备份（省流量）
  • 仅充电时备份（省电量）
  • 备份到服务端 /Photos/年-月/ 目录

7.3 离线收藏

在文件列表中点击 ⭐ 图标，文件将下载到手机本地。即使断网也能在「离线收藏」标签页中打开。

8. 外网访问

默认情况下，客户端只能在同一局域网内连接服务端。如需在公司或外出时访问家里的文件，需要在路由器上设置端口转发：

设置步骤

  1. 登录路由器管理页面（通常是 http://192.168.1.1）
  2. 找到「端口转发」或「虚拟服务器」设置
  3. 添加规则：外部端口 8443 → 内部 IP（台式机地址）→ 内部端口 8443
  4. 协议选择 TCP
  5. 保存并应用

设置完成后，客户端地址改为 http://你的公网IP:8443（公网 IP 在 ip.sx 查看）。

安全提醒：公网暴露端口后，任何知道 Token 的人都能访问你的文件。请确保 Token 足够复杂且不泄露。

9. 故障排查

问题可能原因解决方法
客户端连不上服务端 服务端未运行 / 防火墙阻止 / IP 地址错误 检查服务端是否开机、防火墙是否放行 8443 端口、IP 地址是否正确

10. 常见问题

Q: 同步文件夹可以放在 D 盘吗？

可以。首次配置时选择 D 盘路径即可，或稍后在设置中修改。

Q: 能限制同步速度吗？

能。设置 → 带宽限制，输入上传/下载速率上限（KB/s）。

Q: 换电脑了怎么迁移？

在新电脑上安装客户端，输入相同的服务端地址和 Token 即可。文件会自动从服务端下载。

Q: 服务端需要一直开着吗？

是的。服务端关机期间，各设备之间的同步会暂停。服务端重新开机后会自动追赶。

Q: 支持 macOS / iPhone 吗？

当前版本仅支持 Windows 和 Android。iOS 版本在计划中。

Q: 数据安全吗？

所有文件存储在你自己的硬盘上。传输使用 HTTPS 加密。Token 使用 DPAPI 加密存储。不经过任何第三方服务器。
