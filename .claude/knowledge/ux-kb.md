# UX 审查知识库（CloudPan）

> 供任务产生者 task-producer 及其 UX 审查子 Agent 使用。用户画像：家庭用户（含老人、小孩、非技术人员）。
> **通用启发式见本文件；网盘产品层（页面设计/交互模式）见 [clouddrive-kb.md](clouddrive-kb.md)，视觉美化见 [visual-design-kb.md](visual-design-kb.md)，三者配合使用。**
> **目标服务**：可被 `goals.json` 的 `goal.kbRef` 引用为 assess 目标判据来源（文件 + §章节）。

## 1. 四大零原则（项目绑定）

1. **零学习成本**：无需读文档、无需培训、无需思考
2. **零等待焦虑**：任何 >1s 的操作有进度反馈
3. **零困惑**：错误信息用普通人语言 + 给出下一步动作
4. **零记忆负担**：系统记住偏好与默认值

## 2. Nielsen 10 大启发式（映射家庭场景）

1. 系统状态可见（进度、在线/离线指示）
2. 系统与真实世界匹配（白话，不用术语）
3. 用户控制与自由（可撤销、可退出）
4. 一致性与标准（同义同形、位置一致）
5. 错误预防（确认对话框、禁用无效操作）
6. 识别优于回忆（默认值、历史记录、自动填充）
7. 灵活高效（常用操作 ≤3 步）
8. 美观简洁（删除多余信息）
9. 帮助用户识别并恢复错误（错误信息 = 原因 + 下一步）
10. 帮助文档（仅当确实需要）

## 3. 无障碍要点（WCAG 2.1 AA 摘选）

- 文本对比度 ≥ 4.5:1
- 可键盘操作、焦点可见
- 错误识别与建议可感知（非仅颜色）
- 字体/窗口可缩放不破版

## 4. 审查检查点

- **首次配置**：步数、默认值、引导提示
- **信息架构**：操作步骤数、重复操作
- **错误处理**：措辞可理解、恢复路径明确
- **反馈**：>1s 进度、后台任务可见
- **视觉**：一致性、层次、可读性
- **空/加载/断网状态**：有说明、有动作

## 5. 修复取向（删减优先）

`删除`（多余步骤/文字/选项）→ `默认`（合理默认值）→ `添加`（必要提示/反馈）

## 6. 审查问题清单

- [ ] 首次配置能否在无指导下 3 步内完成？
- [ ] 错误提示是否含"原因 + 下一步"？
- [ ] >1s 操作有无进度反馈？
- [ ] 系统是否记住用户选择？
- [ ] 有无专业术语 / 需要记忆的操作？
