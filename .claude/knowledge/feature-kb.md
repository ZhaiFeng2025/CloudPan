# 功能审查知识库（CloudPan）

> 供任务产生者 task-producer 及其功能审查子 Agent 使用。判据：功能解决**真实家庭用户需求**、不多不少、边界场景有恢复路径。
> 本文件聚焦功能逻辑与边界；**产品形态（页面如何承载功能）见 [clouddrive-kb.md](clouddrive-kb.md)。**

## 1. 家庭云盘功能域

核心：双向同步、上传下载、冲突解决、版本历史、回收站、分享链接、缩略图、多设备、离线可用、限速、配额、搜索、UDP 局域网发现、WebSocket 实时推送。

## 2. v1.0 声明功能（必须完整且合理）

文件同步 / 版本 / 回收站 / 分块上传 / 分享 / 缩略图 / 冲突 / 限速 / 管理面板 / UDP 发现。
每项检查三问：主路径正确？边界覆盖？失败可恢复？

## 3. 边界场景清单（功能审查必查）

- **大文件**：分块上传、断点续传、哈希校验
- **海量小文件**：相册（数千照片）同步吞吐、缩略图生成队列
- **多设备并发**：同时读写同一文件、版本冲突、设备在线状态
- **断网/弱网**：客户端重连、队列持久化、恢复续传
- **磁盘满/服务端重启**：一致性恢复、不丢数据
- **特殊文件**：Unicode 文件名、符号链接、NTFS 替代数据流、只读文件
- **权限与分享**：密码、过期、越权访问

## 4. 竞品取舍（合理性参照）

| 竞品 | 特征 | 借鉴 |
|---|---|---|
| Nextcloud | WebDAV + 应用生态（重） | 高配家庭/多用户 |
| Syncthing | P2P 同步，无服务器存储（轻） | 简洁同步，无版本/分享 |
| Seafile | 块级去重、加密库（专业复杂） | 大库/加密场景 |
| Dropbox/坚果云 | 智能同步、冲突提示、回收站保留期（Dropbox 免费 30 天 / 付费 180 天，坚果云 30 天） | 默认值、冲突 UX 最佳实践 |

判据：功能必须为家庭用户服务，**拒绝"为了技术炫技"的功能**。

## 5. 过度设计信号（功能维度）

- 无用户场景支撑的设置项
- 可自动化的操作要求手动配置
- 一个功能需要用户理解底层概念才能用（如"WebSocket 长连接""分块"）

## 6. 审查问题清单

- [ ] 该功能解决什么真实家庭场景？不解决就不该存在
- [ ] 主路径可用？失败路径可恢复？
- [ ] 默认值是否合理（安全、常用）？
- [ ] 大文件 / 海量小文件 / 多设备 / 断网 是否覆盖？
- [ ] 有无可删除的冗余功能？
