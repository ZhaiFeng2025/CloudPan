# 视觉美化设计知识库（CloudPan）

> 供任务产生者 task-producer 及其 UX/视觉审查子 Agent 使用。聚焦网盘**视觉美化**：配色、字体、间距、层次、状态色、深色模式。与 [ux-kb.md](ux-kb.md)（易用性）、[clouddrive-kb.md](clouddrive-kb.md)（页面/交互）互补——前两者答"好不好用、页面怎么排"，本文件答"好不好看、视觉是否统一专业"。
> **目标服务**：可被 `goals.json` 的 `goal.kbRef` 引用为 assess 目标判据来源（文件 + §章节）。

## 1. 设计令牌（Design Tokens，禁止随手取色）

所有颜色/间距/圆角/字号必须来自**统一令牌**，禁止在代码里硬编码散色值。

- **色彩令牌**：主色 / 成功 / 警告 / 危险 / 信息；文本（主/次/弱）；背景（主/次/悬浮）；边框；选中
- **间距刻度**：`4 / 8 / 12 / 16 / 24 / 32`（4px 基准）
- **字号刻度**：`12 / 13 / 14 / 16 / 20 / 24 / 32`，行高 1.4-1.5
- **圆角刻度**：`4 / 8 / 12 / 16`
- **阴影层级**：0（平面）/ 1（卡片）/ 2（弹层）三级，禁用过深阴影

## 2. 视觉层次（Visual Hierarchy）

- 每个页面**有且仅有一个主行动点**（primary action），其余为次级/文字按钮
- 层次靠 **字号 + 字重 + 颜色** 三重差异区分，禁止只靠颜色或只靠字号
- 信息强度用文本色阶（主/次/弱），不用大量边框堆砌
- 卡片/分组靠**间距与留白**区分，不滥用边框与底色

## 3. 配色原则

- **主色 ≤ 1、强调色 ≤ 1**，中性色若干；状态色（成功/警告/危险/信息）全局语义统一
- 正文对比度 ≥ 4.5:1、大字 ≥ 3:1（WCAG 1.4.3）
- 不用纯黑/纯白（用 `#1a1a1a` / `#f7f8fa` 类柔和值）
- 同步状态色固定语义：`✓ 成功绿 / ↻ 同步中蓝 / ! 冲突琥珀 / ✗ 失败红`（对齐 clouddrive-kb §4）

## 4. 字体与排版

- 中文优先：Win 用微软雅黑、Android 用系统默认；数字/英文可用系统等宽
- 正文 14px、标题 16-20、副标题 13-14、辅助 12
- 长列表行高 ≥ 1.4；文本行宽不宜过窄/过宽
- 不使用纯视觉装饰性字体，不用全大写中文（不适用）或过多字重混排

## 5. 状态与反馈的视觉

- 同步/在线状态**图标 + 颜色双通道**（不只靠颜色，符合 WCAG 1.4.1）
- 进度条/加载统一样式；>1s 操作显示
- 空状态：插画或图标 + 一句话说明 + 行动按钮，**禁止空白页**
- 错误：危险色 + 图标 + 原因 + 下一步

## 6. 深色模式

- 若实现深色模式：**令牌级切换**（语义色 → 深色值），禁止硬编码反色/取反
- 深色下对比度仍达标；阴影减弱、改用边框区分层级

## 7. 平台一致性

- WinForms：跟随 Win11 现代风格（圆角、浅色卡片、充足间距）；深色模式跟随系统
- Android：Material Design 3（可选动态主题色）；两平台**令牌同源**、视觉行为一致
- 图标风格统一（线性/填充一致、圆角一致）；文件类型图标语义一致（文件夹/图片/文档/视频/音频/压缩包）

## 8. 竞品视觉参照

| 竞品 | 视觉特征 | 可借鉴 |
|---|---|---|
| Dropbox | 干净、绿主色、留白充足、卡片轻阴影 | 简洁优雅 |
| 坚果云 | 蓝主色、实用主义 | 桌面工具感 |
| 阿里云盘 | 白底、现代、强调色克制、间距舒适 | 国内现代审美 |

| OneDrive | 蓝色调、Windows 原生感 | Win 平台一致性 |

## 9. 美化审查清单

- [ ] 颜色是否全部来自令牌？有无硬编码散色值？
- [ ] 页面主行动点是否唯一、明显？
- [ ] 视觉层次是否靠 字号+字重+颜色 三重差异？
- [ ] 间距是否遵循刻度（4/8/12/16/24/32）？
- [ ] 状态是否 图标+颜色 双通道、语义色全局统一？
- [ ] 正文对比度是否 ≥4.5:1？
- [ ] 空状态/加载/错误是否有设计？
- [ ] 深色模式（若实现）是否令牌级切换？
- [ ] Win/Android 是否同源令牌、视觉一致？
- [ ] 有无纯黑/纯白、过深阴影、随意配色？
