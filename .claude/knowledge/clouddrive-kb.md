# 网盘产品设计与交互知识库（CloudPan）

> 供任务产生者 task-producer 及其 UX 审查子 Agent 使用。聚焦**网盘产品层**：功能形态、页面设计与交互模式。与 [ux-kb.md](ux-kb.md)（通用启发式）互补——前者回答"网盘该长什么样、怎么操作"，后者回答"什么样的体验才算好"。

## 1. 网盘产品形态与信息架构

- **主导航**（家庭版可精简为 3-4 项）：文件 / 共享 / 回收站 / 设置；扩展项：最近、收藏、离线、相册
- **文件浏览**：面包屑 + 路径跳转；**网格视图**（图片/相册）与**列表视图**（文档）切换；排序（名称/时间/大小）、升序降序
- **文件详情面板**：预览、属性（大小/时间/哈希）、版本历史入口、分享入口
- **状态区**：同步状态（在线/离线）、上传下载队列、配额用量（家庭场景可选）
- **设置页**：同步根路径、选择性同步、限速、通知、设备管理

## 2. 核心页面设计

| 页面 | 关键元素 |
|---|---|
| 文件列表 | 工具栏（上传/新建文件夹/搜索）、视图切换、多选、右键菜单、空状态引导 |
| 同步面板 | 每文件状态图标 + 汇总进度条 + 队列剩余 + 冲突/失败入口 |
| 分享页 | 链接生成、权限（只读/可编辑/密码/过期）、已分享列表、撤销 |
| 回收站 | 恢复/彻底删除、保留期限提示 |
| 首启引导 | 空状态 + "拖拽文件到此开始同步" + 同步根配置 |

## 3. 文件操作交互

- **上传**：拖拽到窗口/文件夹 + 文件选择器 + 批量；上传队列可视化，可暂停/取消
- **下载/预览**：下载进度 + 完成通知；预览优先于下载（图片/文档直接看）
- **右键上下文菜单**：预览/下载/分享/重命名/移动/复制/删除/版本历史——**高频操作 ≤3 步**
- **多选**：CheckBox 常显 + Ctrl/Shift 扩展；批量下载/删除/分享/移动
- **移动/复制**：拖拽或对话框，支持跨目录
- **搜索**：即时过滤，按名称/类型
- **删除**：确认 + 可撤销；**进回收站而非物理删除**
- **重命名/冲突**：重名时提示"保留两者/替换/比较版本"，不静默覆盖

## 4. 同步状态与反馈

- 每文件状态图标：`✓` 已同步 / `↻` 同步中 / `!` 冲突 / `✗` 失败 / `☁` 仅云端
- 汇总进度条 + 剩余文件数；>1s 操作必有进度反馈
- **冲突交互**：提示"该文件两端都有修改"→ 选项（保留本机/保留云端/两者都留/查看版本对比）
- **断网/重连**：状态徽标切换 + 自动重连提示；恢复后自动补齐同步，无需手动
- **失败恢复**：失败项可见可重试，错误信息 = 原因 + 下一步

## 5. 分享交互

- 创建：选文件 → 分享 → 链接 + 权限（只读/可编辑/密码/过期时间）
- 管理：已分享列表、撤销链接、改权限
- 接收方体验：链接打开直接预览/下载（家庭局域网场景可免登录）

## 6. 设置/配置交互

- 首次配置：服务端 URL + Token + 同步根，**3 步内完成**，有引导与默认值
- 选择性同步：勾选目录树，改动即时生效
- 限速：滑动条或数字，含单位换算；改动即时生效，无需重启
- 设备管理：查看/撤销已配对设备

## 7. 移动端与家庭场景特化

- **手机**：底部导航（文件/相册/共享/我的）、照片墙缩略图、下拉刷新、侧滑操作、预览滑动翻页
- **相册**：按时间分组、多选批量、自动备份开关（家人手机照片自动同步）
- **家庭共享**：家庭成员空间/共享相册，老人默认只读
- **老人小孩**：大图标、白话文案、操作 ≤3 步、无专业术语（"同步""哈希"→"已保存""正在保存"）

## 8. 竞品页面模式参照

| 竞品 | 页面模式 | 可借鉴 |
|---|---|---|
| 坚果云 / Dropbox | 侧边栏 + 文件列表 + 状态图标 | **同步状态可视化标杆**（✓↻!✗） |
| 百度网盘 / 阿里云盘 | 左侧导航 + 列表/网格 + 在线预览 | 国内用户习惯、批量操作、分享流程 |
| Google Drive / OneDrive | 卡片/列表切换、即时搜索 | 搜索与视图切换 |
| iCloud 相册 / 谷歌相册 | 照片墙自动同步、回忆 | 家庭相册场景 |

## 9. 交互审查清单

- [ ] 主导航是否覆盖家庭用户高频路径（文件/相册/共享/回收站）？是否 ≤4 项？
- [ ] 上传是否支持拖拽 + 批量 + 队列进度 + 暂停？
- [ ] 每个文件是否有清晰的同步状态（含冲突/失败/仅云端）？
- [ ] 删除是否进回收站且可恢复/可撤销？
- [ ] 分享是否 ≤3 步完成，权限/密码/过期可设？
- [ ] 冲突处理是否给出选项而非静默覆盖？
- [ ] 断网/重连有无反馈与自动恢复？
- [ ] 首启空状态有无引导？
- [ ] 移动端照片墙 + 下拉刷新是否可用？
- [ ] 老人/小孩路径：大图标、白话、无术语？
