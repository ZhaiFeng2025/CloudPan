# 安全审查知识库（CloudPan）

> 供任务产生者 task-producer 及其架构/功能审查子 Agent 使用。安全映射进架构（防线）与功能（权限/分享）。家庭云盘存个人数据，安全是最高风险。
> **目标服务**：可被 `goals.json` 的 `goal.kbRef` 引用为 assess 目标判据来源（文件 + §章节）。

## 1. 风险模型

- 家庭局域网默认信任内网，但**端口可能被暴露/被同局域网其他设备访问**
- 个人数据（照片/文档/配置）泄露不可逆
- v1.0 无 TLS（HTTP 明文，家庭局域网声明可接受）——**升级路径须留好**

## 2. OWASP ASVS L1 核心映射

| ASVS 章节 | 对应检查 |
|---|---|
| V2 认证 | Token 认证、无/错 Token → 401、令牌生成强度 |
| V4 访问控制 | 水平/垂直越权（他人文件、他人分享） |
| V5 输入验证 | 路径穿越、参数注入、上传校验 |
| V6 加密与密钥 | 密钥存储（DPAPI）、Token 非明文、口令哈希（PBKDF2） |
| V7/V8 错误与数据保护 | 日志/错误信息不泄露凭据、敏感数据最小暴露 |
| V9 通信 | 传输加密状态、HTTP 明文风险披露 |
| V12 文件操作 | 路径规范化（ValidatePath）、元数据越界读取 |

## 3. 项目已建立防线（审查其完整性）

- `ValidatePath` 路径安全统一防线（上传/下载/缩略图/回收站恢复全链路）
- Token 认证（DPAPI 加密存储、消息级认证）
- 速率限制（60/min 滑动窗口）
- 分享密码 PBKDF2 慢哈希 + 按 IP 限流

## 4. 审查问题清单

- [ ] 输入可被谁控制？恶意输入会产生什么后果？
- [ ] 路径是否全部经 ValidatePath？有无绕过？
- [ ] 越权访问能否读取/修改他人文件或分享？
- [ ] 认证失败是否统一 401、无信息泄露？
- [ ] 日志/错误信息是否泄露路径/Token/密钥？
- [ ] 默认配置是否安全（无默认口令、无开放端口）？
- [ ] TLS 未启用风险是否被声明，升级路径是否存在？
